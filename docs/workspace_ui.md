# 研究工作台：分层导航与界面验收

2026-10-04。此轮是现有 Streamlit 项目的信息架构优化，不更换研究引擎，不训练、发布模型或下单。

## 为什么调整

旧页面由两组各 6 个标签组成，两组选中的内容同屏堆叠；Streamlit 的标签内容都会执行，隐藏的行情、评估、知识库等视图也可能加载资源。侧栏同时放密钥、缓存按钮、策略指标，主研究区又嵌套分钟接入、训练和舆情订阅，日常操作与维护操作难以区分。

新设计采用克制的金融研究工作区风格：浅灰底、深色文字、青色操作强调和琥珀色风险提示。保留原生表单与可访问标签，不新增 UI 框架或外部字体。设计技能指导的是层级和渐进展开，不是用大卡片堆叠替代旧标签。

## 入口映射

| 一级导航 | 二级功能 |
| --- | --- |
| 研究总览 | 因子时点、会话研究状态、三个常用入口、研究流程说明 |
| 市场与舆情 | 行情监控、舆情情报、宏观环境、策略信号 |
| 混合研究 | 候选来源选择、研究问题、模型访问与调用预算、运行报告、显式读取历史 |
| 因子实验室 | 因子分析、因子评估、遗传挖掘 |
| 数据与模型 | 数据准备、模型评估、迭代诊断 |
| 回测与复盘 | 回测表现、交易记忆 |
| 系统设置 | 连接与缓存、定时任务 |

原来可用的 12 个主入口保留并归类；舆情和数据准备从研究页独立出来。原本未接入主界面的旧 RAG/超参数优化入口没有在本次重新启用。

分钟导入入口现在为「数据与模型 → 数据准备 → 行情接入与覆盖 → 分钟行情接入与覆盖审计」。模型连接现在为「系统设置 → 连接与缓存」。

## 实现边界

- `dashboard_workspace.py` 管理导航、轻量总览与样式；只调用当前选中的一个渲染函数，不执行隐藏页面。
- 首页只读取本地因子摘要，不加载模型、不调用 `ctx.signal`、不生成研究结果。过期、无效、未来时间会明确提示；近期数据也不等同于交易就绪。
- 研究页与准备页共用原研究、候选和校验逻辑，默认仍离线。单独打开研究页不读取因子 pickle 或扫描历史目录；需要显式读取或运行。
- 会话内保留二级功能、研究草稿、预算、候选来源、分钟来源；不保留离页后的联网、入库和训练授权。文件仍需自行保存，浏览器刷新并非持久化保证。
- API 密钥使用独立会话键保留，不写环境变量或磁盘；配置密钥不等同于同意在线调用。
- 行情页默认只读本地缓存。开启许可并点击刷新才请求；更改筛选、切换页面或控件重跑不联网。刷新只失效对应项目/合约/周期的内存视图，防止旧缓存覆盖新结果。
- 舆情快照使用 SQLite 只读模式；打开视图不会初始化或迁移数据库。抓取、通知和调度仍是独立显式操作。
- 没有改动行情原文、生产因子、研究报告或模型发布状态。配置页缓存操作只清理进程内缓存。

## 验收范围

自动化覆盖一级/二级路由、首页无隐藏调用、跨页状态与授权隔离、密钥清空/恢复、行情刷新时机与精准缓存失效、准备/研究页面职责分离。所有会写文件或调用服务的路径使用临时目录与替身验证，不执行真实训练或采集。

浏览器验收采用本地工作台、只读导航和桌面/窄屏检查。没有旧版像素级截图基线，视觉回归结论为 **INCONCLUSIVE**；本次截图可用于后续人工比较。未进行完整屏幕阅读器、axe 或 Core Web Vitals 测量，不宣称完整无障碍合规或性能指标达标。
